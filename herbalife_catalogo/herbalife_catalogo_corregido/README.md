# Catálogo Herbalife corregido

Versión con productos cargados, buscador, filtros, paginación, favoritos y ficha de detalle.

## Ejecutar
Abre la carpeta en Visual Studio Code y ejecuta `index.html` con Live Server. Para probar la PWA se requiere localhost o HTTPS.

## Importante sobre los productos
Los nombres, presentaciones y precios iniciales se tomaron del sitio oficial de Herbalife Bolivia consultado el 23/11/2026. Los precios pueden cambiar. No se añadieron fotografías de envases porque no se descargaron imágenes oficiales verificadas; por ahora las tarjetas usan un recurso gráfico provisional con la letra H. Sustitúyelo por fotografías autorizadas cuando las tengas.

El formulario valida datos localmente, pero no envía consultas. Los botones de contacto comercial se deben conectar a datos reales.
